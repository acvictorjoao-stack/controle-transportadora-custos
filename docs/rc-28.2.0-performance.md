# RC 28.2.0 — Relatório de Performance

## Baseline (antes)

| Área | Achado |
|------|--------|
| Feedback no clique | Sem highlight/progress imediato |
| Prefetch | Default do Next; sem `prefetch` explícito nem hover na busca |
| Suspense | Quase ausente nas páginas do dashboard |
| `router.refresh()` | ~64 calls; dupla invalidação com `revalidatePath` |
| Cache de referência | Inexistente |
| `select('*')` | Concentrado em filhos de trips/customers |
| PPR | Desligado |
| Bundle | `xlsx` import estático |

## Gargalos priorizados

1. Clique sem feedback perceptivo
2. Páginas RSC bloqueando no `Promise.all` completo (Viagens 8 queries)
3. `router.refresh()` invalidando payload após mutações
4. Selects de cadastro refetchados a cada navegação
5. Dashboard executivo com 2 bundles DRE no caminho crítico

## Depois (implementado nesta RC)

| Otimização | Status |
|------------|--------|
| Navegação otimista + TopProgress | Feito |
| `loading.tsx` faltantes | Feito |
| Suspense Viagens / Dashboard / DRE | Feito |
| Prefetch explícito + staleTimes | Feito |
| Updates locais nas listas (menos refresh) | Feito |
| Cache filiais / centros de custo + tags | Feito |
| Dynamic import charts / xlsx | Feito |
| Selects explícitos em trips | Feito |
| PPR incremental (Home, Dashboard, DRE, Inteligência) | Preparado via Suspense; flag `experimental.ppr` bloqueada no Next 15.4 estável (exige canary) |
| Instrumentação dev (`[perf]` no console) | Feito |

## Como medir

1. Abrir DevTools → Console em `NODE_ENV=development`
2. Navegar Home → Dashboard / Viagens
3. Observar logs `[perf] navegação …ms` e, nos loaders instrumentados, `[perf] query …ms`

## Expectativa de UX

- Home → módulo: skeleton + progress no mesmo frame do clique
- Menu → menu: resposta imediata (staleTimes + prefetch)
- Viagens: tabela primeiro; selects em streaming
- Modais: selects de filiais/centros mais estáveis via cache
